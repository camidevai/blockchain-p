# FlavorFi - Presentación Interactiva

Presentación web interactiva para FlavorFi, una plataforma de gestión y fidelización para negocios de alimentos.

## 🚀 Características

- **Diseño Responsivo**: Funciona perfectamente en desktop, tablet y mobile
- **Animaciones Suaves**: Transiciones fluidas con Framer Motion
- **Modo Oscuro/Claro**: Soporte completo para ambos temas
- **Modales Interactivos**: Componentes modales con animaciones
- **Accesibilidad**: Cumple con estándares WCAG AA
- **Colores de Marca**: Paleta de colores personalizada (verde, naranja, verde claro)

## 🛠️ Tecnologías

- **React** - Librería de UI
- **Framer Motion** - Animaciones
- **Tailwind CSS** - Estilos
- **Recharts** - Gráficos
- **Lucide React** - Iconos

## 🎨 Secciones

1. **Hero** - Presentación principal con CTA
2. **El Desafío** - Problemas del sector con modales interactivos
3. **Estadísticas** - Datos clave (60% y 80%)
4. **Soluciones** - Características principales
5. **Estadísticas de Mercado** - Datos de oportunidad
6. **Oportunidad** - Timeline de transformación
7. **Llamada a Acción** - CTA final

## 🌐 Despliegue en Netlify

### Opción 1: Conectar GitHub (Recomendado)

1. Ve a [Netlify](https://netlify.com)
2. Haz clic en "New site from Git"
3. Selecciona GitHub y autoriza
4. Selecciona el repositorio `blockchain-p`
5. Netlify detectará automáticamente la configuración
6. Haz clic en "Deploy site"

### Opción 2: Drag & Drop

1. Ve a [Netlify](https://netlify.com)
2. Arrastra la carpeta del proyecto a la zona de drop
3. Tu sitio estará en vivo en segundos

### Opción 3: CLI

```bash
npm install -g netlify-cli
netlify deploy --prod
```
